# 5. ルール・規定・図面

<div id="sub-rule-detail"></div>

## 📏 大会規定

### ⏱ 試合時間・イニング進行ルール

<Card>
1. **試合終了10分前から**
   次の回へは入らない。
2. **終了1分前の時点で**
   その打者を**ラストバッター**とする。
3. **2回表終了時に時間コールド**
   **2回裏は原則行わない**。
   ※ただし、得失点差が順位に関係する大会では裏まで行います。
</Card>

### ⚖️ タイブレーク・勝敗決定方法

<Card>
時間コールドで**同点**の場合、タイブレークを行います。

> 🔔 **タイブレーク設定**
> **1アウト満塁**からスタートします。

それでも勝敗が決まらない場合、以下の優先順位で勝敗を決定します：

1. 「安打数 − 与四死球数」が**多い**
2. 「塁打数」が**多い**
3. 「出塁数」が**多い**
4. 「バッテリーエラー数」が**少ない**
5. 運営による**抽選**
</Card>

## 📐 コート図作成

<Card>
- 体育館のHP等から**フロアの大きさ**を把握した上で作成します。
- コートの向きが把握できれば**細かく作る必要はありません**が、各コートへの**アルファベット振り（A・B・C…）**は確実に行うこと。
</Card>

<Card>
- テープには幅があるため、以下のことに注意して作成すること。
- **投本間はベース後端からテープのベース側の端までの距離であることに注意！（線上は9.22mより遠い）**
- **パスボールライン、アウトラインはベース側とは反対の側まで含めた距離であることに注意！（線上はアウトまたは後逸ではない）**
</Card>

### コート寸法一覧

<Card>
| 項目 | 寸法 |
| :--- | :--- |
| バッターボックス | 90cm × 150cm |
| バッターボックスの外縁とベースの間隔 | 13cm |
| マウンド幅 | 61cm |
| 投本間 | 9.22m |
| アウトラインーベース間 | 8mラインからマウンドまで |
| フェンスラインーベース間 | 13m |
| パスボールライン | ベース中央から255cm |
</Card>

### コート設営の割り振り

<Card>
| 役割 | 必要な用具 | 人数 |
| :--- | :--- |
| 設営監督 | なし | １～２人（企画委員） |
| バッターボックス作成→パスボールライン作成 | 10mメジャー・テープ１巻 | ２～３人 |
| マウンド作成→アウトライン作成 | 10mメジャー・テープ１巻 | ２～３人 | 
| フェンス設置 | 20mメジャー・フェンス（または椅子）・印用のテープ２つ分 | そのほかの人員 |
</Card>

## コート設営の手順

### バッターボックス作成→パスボールライン作成

<Card>
1. メジャーを用いて90cm・150cmのテープを１本ずつ作成。
2. バッターボックスおよびパスボールラインをテープで印をつけ、メジャーはマウンド付近を作成する人に渡す。
3. 作成したものに合わせて４本ずつ複製。
4. バッターボックスの作成。
5. パスボールラインの作成。
</Card>

### マウンド作成→アウトライン作成

<Card>
1. メジャーを用いて61cmのテープを１本作成。
2. メジャーを用いて、ベースの中央線を通るように調整する。
3. メジャーの0mをベースの先端に合わせ、9.22mの位置でマウンドを貼り付ける。
4. アウトラインの作成。
</Card>

### フェンス設置

<Card>
1. メジャーを用いて、ベースに沿うように13m位置まで伸ばす。（この際、8mの位置に印をつけておく。）
2. フェンスを順に置き、メジャーも一緒に移動しながら整える。
3. 反対側まで来たら、同じく8mの位置に印をつける。
</Card>
